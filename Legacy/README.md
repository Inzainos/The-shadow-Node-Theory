# Legacy

Registro de datasets, scripts, figuras y exportaciones históricas que no forman
parte del pipeline ni de los hallazgos activos. La evidencia vigente y su estado
de reproducibilidad se documentan en el README principal y en
`reconstruction_real/audits/`.

El snapshot de Zerve no incluye el dataset de origen; sus scripts dependen del
entorno exportado y no constituyen un pipeline reproducible independiente. Para
los resultados actuales de HackerEarth, consultar
`reconstruction_real/audits/REVISION_REPORTE_HACKEREARTH_2026-10-18.md` y
`data/hackerearth_zerve/NUMEROS_REALES_2026-10-18.md`.

El snapshot se importó desde `origin/zerve`, commits `a4fef75` y `ee89267`.
